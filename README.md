# HolaTodos
Aplicación desarrollada para la materia de Programación de Dispositivos Móviles.

Para compilar y ejecutar el proyecto se necesita:

-


Ejecución de la aplicación

Abrir Android Studio.

Ir a Tools - Device Manager.

Crear o seleccionar un dispositivo virtual Android.

Iniciar el emulador presionando el botón.

Seleccionar el dispositivo en la barra superior de Android Studio.

Seleccionar el icono de elefante.

Seleccionar la configuración app.

Presionar el botón Run.

La aplicación se instalará y ejecutará en el emulador.
